# metadata

데이터가 **"이렇게 되어야 한다"는 기준**을 모아 두는 곳. 정제하면서 채워져도 되지만, 실행할 때마다 자동으로 덮어쓰지 않는다.
코드가 뽑은 초안은 사람이 확인한 뒤 반영한다. 형식은 CSV, 파일명 접두어로 구분한다.

| 접두어 | 내용 |
|---|---|
| `std_` | 표준 (용어, 도메인, 코드, 단어 사전, 코드 변환 규칙) |
| `src_` | 원천 설명 (시스템, 파일 목록) |
| `ds_` | 데이터셋 정의 (데이터셋 목록, 컬럼 사전) |
| `rule_` | 규칙 (업무 규칙, 품질 검사 규칙) |
| `cln_` | 03 실버 정제 기준 (플래그 정의, 코드값, 상태 매핑, 업종 분류, 파라미터, 자리표시 값). `docs/silver_정제.md` 6장. **초안 — 팀 합의 전** |
| `known_issues.csv` | 오염 정답지: 원천에서 발견한 오염과 기대 건수 (필요하면 일부러 넣은 오염도). 03 결과와 비교 |

실행 결과(변환 건수, 검증 결과)는 여기가 아니라 `report/`에 둔다.
