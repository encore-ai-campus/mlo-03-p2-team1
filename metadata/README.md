# metadata

데이터가 **"이렇게 되어야 한다"는 기준**을 모아 두는 곳. 정제하면서 채워져도 되지만, 실행할 때마다 자동으로 덮어쓰지 않는다.
코드가 뽑은 초안은 사람이 확인한 뒤 반영한다. 형식은 CSV, 파일명 접두어로 구분한다.

| 접두어 | 내용 | 예시 |
|---|---|---|
| `std_` | 표준 (용어, 도메인, 코드, 단어 사전, 코드 변환 규칙) | `std_code.csv`: 성별 `M/F/U` / `std_code_map.csv`: `남` → `M` |
| `src_` | 원천 설명 (시스템, 비정형 파일 목록) | `src_system.csv`: 인코딩, 날짜 형식 |
| `ds_` | 데이터셋 정의 (데이터셋 목록, 컬럼 사전) | `ds_column.csv`: `phone` string, null 불가 |
| `rule_` | 규칙 (업무 규칙, 품질 검사 규칙) | `rule_dq.csv`: `phone_not_null` |
| `known_issues.csv` | 일부러 넣은 오염 목록 (정답지) | 성별 코드 혼재 1,630건 |

실행 결과(변환 건수, 검증 결과)는 여기가 아니라 `report/`에 둔다.
