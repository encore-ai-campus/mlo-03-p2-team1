## 1. 프로젝트 개요 및 목표

> 출처: L8–17

대한민국(남한) 전역의 아파트 제곱미터(㎡)당 가격 연간 상승률 예측 결과(실제 상승률 vs AI 예측 오차)와 5대 핵심 입지 시설(일자리, 지하철, 학교, 상권, 병원)의 공간적 영향력을 인터랙티브 3D 지도로 시각화하는 프론트엔드 MLOps 대시보드 프로토타입을 구축했다.

백엔드 API 연동 전에도 한국 부동산의 3대 시장 국면을 즉시 검증할 수 있도록 2020~2026년 7개 연도의 결정론적 Mock 데이터를 내장했다.

### 기술 스택 선택 이유

- **React 18.3 + `@react-three/fiber@^8.17` + `@react-three/drei@^9` + `@react-three/postprocessing@^2.16`:** React 19와 R3F/Postprocessing 간 peer dependency 충돌을 방지하고 안정적인 WebGL 렌더링 파이프라인을 확보하기 위해 React 18 트랙으로 고정.
- **지리 투영:** `d3-geo`(`geoMercator`) + `topojson-client`(`topojson.merge` / `topojson.feature`).
- **상태 관리 & 스타일:** `zustand`(60fps 3D 렌더 루프와 2D HUD 상태 분리), `tailwindcss@^3.4`, `lucide-react`.

## 2. 데이터 스펙 및 행정구역 병합 규칙

> 출처: L21–33

### 행정구역 단위 (229개 시·군·구)

- 오픈소스 `southkorea/southkorea-maps`의 KOSTAT 2018 시군구 TopoJSON(`skorea-municipalities-2018-topo-simple.json`, 원본 250개 영역)을 로드한다.
- 도 지역 내 일반구가 있는 11개 대도시(수원, 성남, 안양, 안산, 고양, 용인, 청주, 천안, 전주, 포항, 창원 — 총 32개 일반구)를 `topojson.merge()`로 각 시 단위 1개로 병합하여 **총 229개 영역**(특별시·광역시 구/군 74 + 세종시 1 + 도 시/군 154)을 구성했다.
- 외부 TopoJSON 네트워크 로드 실패 또는 오프라인 환경에 대비해, 229개 지역의 실제 위·경도 중심점(`centroid`)을 기준으로 경계 클리핑된 다각형 그리드를 자동 생성하는 **Voronoi Fallback 생성기**(`src/utils/koreaGeo.ts`)를 포함했다.

### 3대 시장 국면 Mock 데이터 (2020 ~ 2026, 총 1,603개 레코드)

| 연도 | 국면 코드 | 국면명 | 시장 특성 및 3D 시각화 표현 |
|---|---|---|---|
| 2020~2021 | `BOOM` | 동반 상승기 | 수도권 외곽 및 지방 광역시까지 전국 +10%~+25% 동반 상승. 과소 예측(`+Y`) 네온 막대가 전국 곳곳에서 솟아오름. |
| 2022~2023 | `SLUMP` | 금리 침체기 | 기준금리 인상 충격으로 전국 -5%~-18% 하락. 변동성 과대 지역(세종·대구·인천 등)에서 반투명 지형 하부로 `-Y` 푸른·보라 막대가 깊게 뻗음. |
| 2024~2026 | `POLARIZATION` | 초양극화 국면 | 지방·외곽은 보합/하락으로 어둡게 가라앉고, 서울 핵심지(강남·서초·송파·용산·성동) 및 판교(성남)·과천 등 소수 상급지만 강하게 상승하며 붉은 `+Y` 바늘 막대 급등. |

## 3. 3D 시각화 및 2D HUD 구현 구조

> 출처: L37–57

### 주요 파일 구성 (`frontend/src/`)

- **`types/dashboard.ts`**: `RegionMeta`, `RegionYearRecord`, `YearSummaryMetrics`, `ProjectedRegionGeometry` 등 도메인 타입 정의.
- **`data/regionsMeta.ts`**: 229개 시·군·구 메타데이터(코드, 이름, 시도, 중심 좌표, 등급, 기준 매매가, 5대 시설 점수) 및 일자리 유입 링크(`JOB_FLOW_LINKS`), 광역 철도축(`TRANSIT_CORRIDORS`).
- **`data/mockRegimes.ts`**: 3대 국면 데이터, 연도별 요약 지표(모델 적중률 `|error| <= 2.0%p`, 양극화 지수 상·하위 10% 격차, MAE), 2021년 대비 비교 델타 사전 계산.
- **`components/canvas/RegionPolygon.tsx`**: `actualGrowth`(또는 비교 델타)에 따른 열화상 지형 색상(용암/골드 ↔ 다크 슬레이트 ↔ 딥블루) 및 반투명 다크 글래스 표현(`-Y` 하강 막대 투과 확인 가능).
- **`components/canvas/ErrorBar.tsx`**: 예측 오차(`error = actualGrowth - predictedGrowth`) 전용 3D 막대 및 적중 링.
  - `|error| <= 2.0%p`: 지도 표면 시안/에메랄드 발광 링
  - `error > 2.0%p`: `+Y` 주황~붉은 네온 막대
  - `error < -2.0%p`: `-Y` 푸른~보라 네온 막대 (지형 하부 투과)
  - 비선형 높이 보정 `Math.pow(Math.abs(error), 0.72)` 및 부드러운 보간 애니메이션 적용.
- **`components/canvas/FacilityEffects.tsx`**:
  - `jobs`: 베드타운 → 주요 업무지구 `QuadraticBezierCurve3` 곡선 및 유입 입자
  - `subway`: 수도권 GTX·지하철 및 광역시 핵심 철도축 펄스 이동
  - `school` · `commercial` · `hospital`: 필터 활성화 또는 지역 클릭/호버 시 동심원 빛 파동(`Ripple Ring`)
- **`components/hud/`**:
  - `TopStatusBar.tsx`: 연도, 국면 배지, 모델 적중률, 양극화 지수, 절전(Eco) 토글, KOSTAT/Fallback 전환, 전체 시점 리셋.
  - `LeftFilterPanel.tsx`: 초양극화 스포트라이트(상위 10% 강조 / 하위 90% 와이어프레임), 2021 대비 비교 모드, 5대 시설 레이어 토글, 3D 범례.
  - `RightDetailCard.tsx`: 지역 클릭/호버 시 매매가, 실제 vs AI 예측 vs 오차 비교 바, 5대 시설 SVG 레이더 차트, 핵심 기여 요인 TOP 2 표시(미선택 시 국면 브리핑 TOP 5 퀵 포커스).
  - `TimelineSlider.tsx`: 2020~2026 연도 선택 및 자동 재생(`Play / Pause`).

## 4. 사용자 피드백 및 개선 이력

> 출처: L61–72

### ① 외부 기기 접속 지원 (`vite.config.ts`)

- 다른 노트북에서 LAN으로 대시보드에 접속할 수 있도록 `vite.config.ts`에 `server: { host: '0.0.0.0', port: 5173 }` 바인딩을 추가했다.
- Windows 방화벽 인바운드 `TCP 5173` 포트가 막혀 있을 경우 관리자 권한 PowerShell에서 아래 명령으로 허용할 수 있도록 안내했다:
  ```powershell
  New-NetFirewallRule -DisplayName "ApartApart Vite 5173" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow -Profile Any
  ```

### ② 카메라 조작 UX 개선 (`KoreaMapScene.tsx`)

- 초기 자유 3D 회전(`OrbitControls`)은 지도가 위아래/좌우로 과도하게 뒤집혀 조작이 불편하다는 피드백이 있었다.
- 1차로 회전 각도를 제한했다가, 최종적으로 **회전을 완전히 잠그고(`enableRotate={false}`)** 정북 기준 약 43° 고정 시점(`[0, 26, 25]`)에서 **좌클릭/우클릭/한 손가락 드래그만으로 동서남북 수평 패닝(`screenSpacePanning={false}`)** 이 되도록 변경했다.

## 5. 노트북 팬 소음 원인 분석 및 1·2차 최적화

> 출처: L76–95

대시보드를 띄웠을 때 노트북 팬이 강하게 도는 문제를 해결하기 위해 `Gemini 4 Argon (High)` 모델로 전체 WebGL/R3F 코드를 리뷰받고, 2단계에 걸쳐 대규모 최적화를 수행했다.

### 1차 최적화 (Argon 코드 리뷰 반영)

1. **프레임당 힙 할당 제거 (`colorScales.ts`, `mockRegimes.ts`):** 매 프레임 수백~수천 개 생성되던 `new THREE.Color()` 및 비교 델타 객체 할당을 모듈 스코프 스크래치 객체 재사용 및 초기 사전 계산으로 제거.
2. **`ErrorBar` `InstancedMesh` 통합 (`ErrorBar.tsx`):** 229개 개별 컴포넌트(최대 458 드로우콜, 916 머티리얼, 229개 `useFrame`)를 **4개 `InstancedMesh` + 단일 `useFrame` + 수렴 슬립**으로 전환(`e.instanceId` 기반 클릭·호버 유지).
3. **시설 이펙트 경량화 (`FacilityEffects.tsx`):** `curve.getPointAt(t, _tempVec)` 무할당 샘플링, 파동 링 `InstancedMesh`(`AdditiveBlending`) 통합, 토글 시 `visible` 전환으로 셰이더 재컴파일 방지.
4. **후처리·HUD·지형 로드 경량화:** `EffectComposer multisampling={0}`, `Bloom levels={5}`, 중복 하단 그리드/조명 제거, `.hud-glass` 블러 반경 `18px → 8px` 축소(`contain: paint`), Fallback 지형 지연 생성(`koreaGeo.ts`).

### 2차 심층 최적화 (드로우콜 극소화 & 적응형 프레임 제어)

1. **`RegionPolygon` 458 드로우콜 → 2 드로우콜 병합 (`RegionPolygon.tsx`):**
   - 229개 지형 `ExtrudeGeometry`와 229개 외곽선 `EdgesGeometry`를 각각 단일 `BufferGeometry`로 병합.
   - PBR `MeshStandardMaterial` 대신 경량 `MeshLambertMaterial` + 4채널 RGBA `vertexColors` + `faceToRegion` `Uint16Array` O(1) 피킹을 적용해 투명 객체 CPU 정렬과 레이캐스팅 부하를 대폭 축소.
2. **`FacilityEffects` 32개 `Line2` → 2개 `LineSegments` 병합 (`FacilityEffects.tsx`):**
   - 일자리 곡선 25개와 지하철 축 7개를 각각 단일 `LineSegments` 버퍼로 병합.
3. **적응형 `frameloop="demand"` & 절전(Eco) 모드 (`KoreaMapScene.tsx`, `TopStatusBar.tsx`):**
   - 풀스크린 `<Grid infiniteGrid />` 프래그먼트 셰이더를 경량 `<gridHelper>`로 교체.
   - `AdaptiveFrameDriver`를 통해 **백그라운드 탭 `0 FPS`**, **조작/전환 직후(1.2초) 최대 `60 FPS`**, **유휴 상태 `30 FPS`** 로 자동 조절.
   - 상단 **절전(Eco)** 버튼 활성화 시 `<EffectComposer>`/`<Bloom>` 비활성화 + `dpr={1}` + 유휴 `18 FPS`로 노트북 발열과 팬 소음을 최소화.
