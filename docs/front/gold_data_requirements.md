# 프론트엔드에서 본 Gold 데이터 요구사항

## 1. 화면에서 확인한 범위

로컬 대시보드 첫 화면, 용산구 상세 카드, 2021년 대비 비교 모드를 확인했다. 화면에는 지도 색상과 예측 오차 막대, ㎡당 매매가, 실제·예측 상승률, 입지 점수, 상위 지역과 연도별 요약이 표시된다.

현재 화면은 **전국 시·군·구 × 연도**의 모의 데이터로 동작한다. 실제 연결의 기준은 프로젝트 분석 범위인 **서울 법정동 × 분기**로 잡는다. 이를 위해 화면의 지도를 법정동 경계 또는 중심점에 연결하고, 기간 선택과 요약 집계도 같은 지역·분기 기준으로 맞춘다. 2021년 비교 기능을 유지할 경우 어떤 분기를 기준으로 삼을지 함께 정한다. [대시보드 매뉴얼](../manual/09_프론트엔드_3D_대시보드.md) · [프론트엔드 타입](../../frontend/src/types/dashboard.ts)

## 2. 화면이 요구하는 데이터

| 화면·기능 | 필요한 데이터 | 어디에서 제공할지 |
| --- | --- | --- |
| 3D 지도·지역 선택 | 법정동 코드와 이름, 자치구 이름, 지역 경계 또는 중심점, 실제 가격 상승률 | 코드·이름은 Silver `ldong_code`를 사용한다. 경계·중심점은 법정동 코드에 연결할 별도 지도 자료가 필요하다. 상승률은 Gold 실측 가격에서 계산한다. |
| 지역 상세 카드 | ㎡당 매매가, 실제 상승률, 예측 상승률, 오차, 입지 지표 | 매매가는 Gold, 예측값은 모델 결과에서 가져온다. 오차는 동일 지역·기간의 실측과 예측을 맞춰 계산한다. 거래 건수도 함께 제공하면 표시된 가격의 표본 규모를 알 수 있다. |
| 입지 레이어·레이더 | 현재 화면의 일자리·철도·학교·상권·상급종합병원 점수와 상위 2개 요인 | 1차에는 확인 가능한 인허가 5종의 실제 업소 수를 제공한다. 현재 점수·철도 경로·업무지구 연결에는 별도 원천과 산식이 필요하다. 상위 요인을 모델 기여도로 표시하려면 모델의 설명 결과가 필요하다. |
| 타임라인·2021 비교 | 선택 기간, 비교 기준 기간, 양쪽 기간의 ㎡당 가격과 상승률 | `dim_date`와 Gold 분기 마트를 사용한다. 가격 변화율과 상승률 차이를 각각 계산한다. 예측 오차의 변화까지 보려면 기준 기간에도 모델 평가 결과가 있어야 한다. |
| 상단 요약·스포트라이트·TOP 5 | 실제 상승률 평균, 상·하위 10% 격차, 상위 지역, 모델 적중률과 MAE, 시장 국면 표시 | 순위·평균·격차는 유효한 지역의 상승률로 계산한다. 적중률·MAE는 실측과 예측이 모두 있는 지역에 대해 계산한다. 시장 국면 라벨과 브리핑 문구에는 별도 분류 기준이 필요하다. |

| 1차 | `apt_trade` | `LDONG_CD`, `SGG_CD`, `DEAL_DTM`, `DEAL_AMT_NUM`, `EXCL_AREA_NUM`, `CNCL_YN`. 지역·계약일로 묶고 취소 신고를 제외해 ㎡당 가격·거래 건수를 만든다. `APT_KEY`, `APT_NM`, `BUILD_YEAR_NUM`은 단지 분석에 사용한다. 원천 행 키와 `SAME_DEAL_YN`을 보존해 의심 거래를 추적한다. |
| 1차 | `ldong_code` | `LDONG_CD`, `LDONG_NM`, `SGG_CD`, `SGG_NM`, `SIDO_NM`, `ABL_YN`. 거래·입지·지도에 동일한 지역 기준을 적용한다. 지도 코드와 조인했을 때 중복과 미매칭 건수를 확인한다. |
| 1차 | `food_general`, `food_rest`, `clinic`, `pharmacy`, `beauty` | `LDONG_CD`, `LDONG_SRC_CD`, `LGOV_CD`, `ANLS_INDUTY_CD`, `ANLS_LCNS_DTM`, `ANLS_CLSBIZ_DTM`, `OUT_SCOPE_YN`, `ABNRM_LCNS_DTM_YN`. 일반음식점·카페·휴게음식점·의원·약국·미용업의 분기별 개업·폐업·기말 영업 수를 만든다. 이전·재등록·교체를 조정하는 지표가 필요하면 `MOVE_PRE_KEY`, `REPL_PRE_KEY`, `REPL_TYPE_CD`도 사용한다. |
| 후속 | `store_info`, `hira_inst` | `LDONG_CD`와 상가 `STORE_KEY`·`INDUTY_SCLS_CD`, 의료기관 `MED_INST_KEY`·`INST_TYPE_CD`로 월별 현황을 만든다. 제공된 Silver ZIP에서는 두 자료 모두 **2026년 9월 한 시점**이므로 해당 시점의 조회나 인허가 지표 대조에 사용한다. 상권 접근성이나 과거 분기별 의료 인프라 점수에는 추가 근거가 필요하다. |
| 후속 | `apt_rent` | 계약일·법정동·보증금·월세. 현재 매매가 상세 화면에 전월세 지표가 추가될 때 별도 계약 팩트로 제공한다. |

원천 컬럼과 집계 예외는 [Silver 컬럼 정의](../../metadata/std_term.csv)와 [Gold 확정 집계 기준](../manual/07_데이터모델_ERD와_Gold.md#4-골드-집계-기준-고정)을 따른다.

## 4. Gold 팩트·차원 구성

| 테이블 | 한 행의 단위 | 담을 내용과 구성 이유 |
| --- | --- | --- |
| `fact_apt_trd` | 매매 신고 1건 | 지역·거래일·단지 키, 거래금액(원), 전용면적(㎡), ㎡당 매매가(원/㎡), 출처·품질 정보. 개별 거래를 보존하면 동·구·분기별로 정확한 중앙값을 다시 계산할 수 있다. |
| `fact_lcns_qtr` | 법정동 × 분기 × 인허가 업종 | 지역·분기·업종 키, 개업 수·폐업 수·분기 말 영업 수와 품질 정보. 업종을 행으로 관리하면 업종별 화면 필터와 기간 비교에 같은 지표를 쓸 수 있다. |
| `dim_region` | 법정동 1개 | 법정동 코드·이름, 자치구 코드·이름. 두 팩트가 같은 지역 키를 공유한다. 지도 형상은 법정동 코드로 연결하는 별도 자료로 관리할 수 있다. |
| `dim_date` | 달력 날짜 1일 | 일자·월·분기·연도. 거래는 계약일 키를, 분기 집계는 분기를 대표하는 날짜 키를 참조한다. |
| `dim_lcns_induty` | 인허가 분석 업종 1개 | 업종 코드·표시명·분류 범위. 예를 들어 카페와 휴게음식점(카페·편의점 등을 뺀 나머지)의 집계 범위를 구분할 수 있다. |
| `dim_apt_cmplx` | 식별한 아파트 단지 1곳 | 단지 키·이름·건축연도. 동 내부의 단지별 비교가 필요할 때 사용하며, 현재 지역 카드의 필수 항목은 아니다. |

상가·의료기관 현황을 추가하면 `fact_store_snapshot`은 **법정동 × 기준월 × 상가 업종**, `fact_med_inst_snapshot`은 **법정동 × 기준월 × 의료기관 유형**으로 둔다. 지역·날짜 차원을 공유하고, 각 원천의 분류를 각각 `dim_induty`, `dim_med_inst_type`에 연결하는 안을 제안한다.

## 5. 대시보드에 넘길 결과와 계산 기준

첫 연동은 **`mart_ldong_infra_qtr` 한 행 = 서울 법정동 × 분기**로 잡는다. 매매와 인허가를 각각 집계한 뒤 결합해, 거래 건수가 업종 수만큼 중복되지 않게 한다. 화면에는 법정동 코드·이름, 분기, ㎡당 매매가 중앙값, 거래 건수, 업종별 기말 영업 수와 개업·폐업 수, 잠정·희소 여부를 제공한다.

- **가격과 상승률** — 거래별 `거래금액 ÷ 전용면적`의 중앙값을 사용한다. Gold는 원/㎡로 관리하고 화면에서 만원/㎡로 변환한다. 분기 상승률은 계절 영향을 줄이기 위해 **전년 동분기 대비**를 1차 안으로 제안한다. 두 기간 중 가격이 없거나 기준값이 0이면 상승률은 `NULL`로 제공한다. 거래가 없는 관측 기간은 건수 `0`과 가격 `NULL`로 구분한다.
- **요약과 모델 지표** — 상승률 차이와 오차는 `%p`로 표시한다. 오차는 `실제 상승률 − 예측 상승률`, MAE는 절대 오차 평균, 적중률은 평가 가능한 지역 중 `|오차| ≤ 2%p` 비율이다. 이 기준을 유지하려면 모델도 동일한 기간과 상승률 정의를 사용해야 한다. 예측값은 모델 버전·대상 분기·예측 기준일과 함께 조회한다.
- **비교 범위** — 2021년 대비 비교를 유지한다면 **2021년 같은 분기**를 기준으로 제안한다. 가격 변화는 기준 가격 대비 비율, 상승률 차이는 두 상승률의 차로 계산한다. 자치구 화면이 필요하면 구에 속한 거래에서 중앙값을 다시 구한다. 동별 중앙값을 평균 내는 방식은 구 전체 거래의 중앙값과 달라질 수 있다.
- **입지·시간 범위** — 분기 말 영업 수는 시점별 상태이므로 연도 집계에서 분기 값을 합산하지 않는다. 일자리·학교·철도와 상급종합병원 접근성의 실측 근거를 확보하기 전에는, 제공 가능한 업소 수에 맞춰 레이어 이름과 범례를 정한다. 예측에 사용할 입지 지표는 예측 기준일에 확인할 수 있었던 자료만 사용한다.

대시보드 연동 전에 확정할 사항은 **법정동 지도 자료와 조인 키**, **분기 상승률의 비교 기준**, **2021년 비교 기준**, **거래가 적은 지역의 표시 기준**, **입지 레이어의 실제 표시 항목**이다. 단계별 Gold 집계와 DB 적재는 [Gold 설계 매뉴얼](../manual/07_데이터모델_ERD와_Gold.md), 모델 결과 연결은 [ML 설계 매뉴얼](../manual/08_ML_데이터셋과_적재DB.md)을 참고한다.
