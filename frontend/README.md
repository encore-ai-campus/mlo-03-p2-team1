# frontend

React + TypeScript 대시보드. 지역 부동산 매매가와 예측가를 보여준다.

3D 지도에서 서울 자치구를 선택하면 오른쪽 상세 영역에 해당 구의 법정동 실측, 인허가와 예측이 표시된다. 하단 조회 기간을 변경할 수 있다. 구 경계는 지도 원본의 자치구 이름으로 API 데이터에 연결한다. 예제 데이터로 화면을 보려면 `?demo=1`로 열 수 있다. Vite의 `/api` 프록시는 기본적으로 `http://127.0.0.1:8000`으로 연결된다. 백엔드 포트가 다르면 `VITE_DASHBOARD_API_TARGET`을 설정한다.
